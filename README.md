# Odin Recipes

This project is a basic recipe website created as part of The Odin Project Foundations course.

By completing this project, I will demonstrate my understanding of HTML, including creating pages, adding headings, paragraphs, links, images, lists, and organizing files and directories.

I will also practice using Git and GitHub to create a repository, make commits, and track my project as I build it.
